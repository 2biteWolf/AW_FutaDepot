AW_FutaDepot 0.1.46 — install
=============================

What it is
----------
Portable Windows library launcher (Tk). One folder. No browser.
Drop packs into _FutaMass (one file or folder = one tile).

Quick install (PowerShell)
--------------------------
Expand-Archive -Path .\AW_FutaDepot_0.1.46.zip -DestinationPath .\AW_FutaDepot -Force
cd .\AW_FutaDepot
.\START.bat

# Or run Python UI directly (Python 3 + Tk required):
py -3 ui.py

# Optional: install Python if missing
winget install Python.Python.3.12

# Optional: GitHub CLI for SYNC push/pull
winget install GitHub.cli
gh auth login

Quick install (cmd)
-------------------
mkdir AW_FutaDepot
tar -xf AW_FutaDepot_0.1.46.zip -C AW_FutaDepot
cd AW_FutaDepot
START.bat

Where to put files
------------------
AW_FutaDepot/
  START.bat / AW_FutaDepot.exe   — launch
  ui.py, app.py                  — entry points
  lib/                           — helpers + catalog.json
  docs/                          — SPEC, BF_FUTA, CHAT_DUMP_PROMPT
  channel/                       — version.json + SYNC meta seed
  web/                           — optional index.html
  win/                           — go sources
  _FutaMass/                     — YOUR library root
  icons-custom/                  — optional pasted icons (created by app)
  config.json                    — created on first run (do not ship personal one)

Rules
-----
- Keep program files next to START.bat.
- Do not overwrite your _FutaMass when unpacking a new zip.
- SYNC needs gh on PATH (UI can offer winget install GitHub.cli).
